# Patterns reference

A coding-interview patterns reference — recognising which technique a problem
wants, with a Python template for each — plus the study plan for the Google L4
interview on 8 September 2026.

**Live:** https://kalawhorn.github.io/patterns-reference/

No build step and no dependencies. Two pages sharing one stylesheet:

- `index.html` — the patterns reference
- `google.html` — the Google plan
- `style.css`, `app.js` — shared by both

## index.html

- **Core patterns** — two pointers, read/write, sliding window, hash map,
  prefix sum, stack, greedy frontier, linked lists
- **Search** — binary search and its variants, BFS, DFS, tree recursion
- **When it breaks** — the debug checklist
- **Python glossary** — the syntax that comes up under interview pressure

## google.html

- **What to focus on** — where the hours go, and what to skip on purpose
- **The 19 days** — day by day, with one measurable finish line each
- **How a day runs** — the study block, the 45-minute cadence, the error log
