Part one — core patterns

[0]Two pointers, converging

TriggerSorted array and you want a pair. Or you’re checking symmetry.

One pointer at each end, moving inward. Each comparison discards a candidate, so you finish in one pass instead of checking every pair.

125 Valid Palindrome
python
def isPalindrome(self, s):
    left, right = 0, len(s) - 1

    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1

        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True

isalnum() means “is alphanumeric” — true for letters and digits, false for punctuation and whitespace. So not s[left].isalnum() reads as “this is a character to skip”.

Watch forThe skip loops need left < right in their conditions, or a punctuation-only string walks a pointer off the end.

[1]Two pointers, read / write

Trigger“In place”, “return k”, “no extra space” — removing or reordering elements.

A read pointer scans everything; a write pointer trails behind marking where the next kept value goes.

283 Move Zeroes
python
def moveZeroes(self, nums):
    write = 0

    for read in range(len(nums)):
        if nums[read] != 0:
            nums[write] = nums[read]
            write += 1

    while write < len(nums):
        nums[write] = 0
        write += 1

Because write never passes read, you never overwrite a value you still need. Remove Duplicates (26) and Remove Element (27) use the identical structure and return write. Merge Sorted Array (88) runs it backwards so you fill the padding without clobbering unread values.

Watch fornums = something rebinds a local name and does nothing to the caller’s list. In place means nums[i] = x or nums[:k] = other.

[2]Sliding window

Trigger“Contiguous subarray” or “substring” plus a constraint — longest, shortest, at most k.

Expand right; when the constraint breaks, shrink from the left. Both pointers only move forward, which is what makes it O(n) rather than the O(n²) of checking every subarray.

3 Longest Substring Without Repeating Characters
python
def lengthOfLongestSubstring(self, s):
    seen = set()
    left = 0
    best = 0

    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1

        seen.add(s[right])
        best = max(best, right - left + 1)

    return best
Watch forWindow length is right - left + 1 — both ends are inside the window.

Fixed-size variant

When the window never changes size — substring search, for instance — there is no shrinking. Just slide: for i in range(n - m + 1).

[3]Hash map

Trigger“Have I seen this”, “does a match exist”, counting, duplicates. If you’re writing a nested loop to search for a value, use this instead.
1 Two Sum
python
def twoSum(self, nums, target):
    seen = {}

    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i

    return []
Watch forCheck for the complement before inserting the current number, or a value can pair with itself.

The three things a hash map is for

Almost every hash problem is one of these. Naming which one you’re in tells you what the values should be.

One — membership

“Have I seen this?” Use a set. No values needed.

python
seen = set()
for x in nums:
    if x in seen:
        return True
    seen.add(x)

Two — counting

“How many of each?” Values are numbers.

python
counts = {}
for c in s:
    counts[c] = counts.get(c, 0) + 1

Three — grouping

“Which things share a property?” Keys are the property, values are lists.

python
groups = defaultdict(list)
for word in strs:
    groups[fingerprint(word)].append(word)
return list(groups.values())

A fourth, less common: remembering where something was, with indices as values. That’s Two Sum.

Keys must be hashable

Dict keys and set members must be immutable. This is the constraint that silently blocks the obvious approach.

python
"aet"            # string  - fine
(1, 0, 2)        # tuple   - fine
frozenset(x)     # fine
["a","e","t"]    # list    - TypeError
{"a": 1}         # dict    - TypeError

So a letter-count fingerprint can’t be a dict — convert it to a tuple. Grid coordinates work as seen[(r, c)] but not seen[[r, c]].

Grouping by a computed key

The move behind Group Anagrams: when you need things that share a property grouped together, make the property the key. No comparison between items ever happens.

python
from collections import defaultdict

def groupAnagrams(self, strs):
    groups = defaultdict(list)

    for word in strs:
        key = "".join(sorted(word))     # anagrams share a sorted form
        groups[key].append(word)

    return list(groups.values())

The alternative fingerprint is a 26-slot frequency tuple — tuple(counts), using ord(ch) - ord("a") as the index. Both convert an unhashable fingerprint into a hashable one. Sorting is O(k log k) per word and shorter to write; counting is O(k) and the better answer if an interviewer pushes. Same move solves Group Shifted Strings (249) and Find Duplicate File in System (609).

Two-way mapping

Isomorphic Strings (205) and Word Pattern (290) need consistency in both directions. One dict only enforces one direction — a → dog and b → dog both pass individually, but two letters can’t claim the same word.

python
if val not in mapping:
    if word in used:
        return False
    mapping[val] = word
    used.add(word)
elif mapping[val] != word:
    return False

The alternative is converting both sides to a canonical shape and comparing them.

python
def shape(seq):
    seen = {}
    out = []
    for item in seq:
        if item not in seen:
            seen[item] = len(seen)      # first distinct -> 0, second -> 1
        out.append(seen[item])
    return out

return shape(pattern) == shape(words)

"abba" and ["dog","cat","cat","dog"] both become [0,1,1,0].

Mistakes to check for

Rebinding instead of assigning into

The most common one by far. Same error as nums = result instead of nums[:k] = result.

python
storage = {letter: 1}        # replaces the WHOLE dict
storage[letter] = 1          # sets one key - what you meant

Reading a key to test whether it exists

python
if storage[key] not in storage:    # KeyError on the first pass
if key not in storage:             # correct

get() without a default

Returns None, and None != 0 is true — so the check you meant to fail quietly passes.

python
storage.get(letter)          # None if absent
storage.get(letter, 0)       # 0 if absent - almost always what you want

get() when the value can be falsy

A key holding 0 looks identical to a missing key. Use in when existence itself is the question.

python
storage = {"a": 0}
if storage.get("a"):      # False - but the key exists
if "a" in storage:        # True  - correct

Treating the returned value as an object

storage.get(k) returns the value itself. There is no .value on it.

append returns None

python
storage[k] = storage[k].append(x)    # sets the value to None
storage[k].append(x)                 # correct - no assignment

Appending to a key that doesn’t exist yet

python
storage.setdefault(k, []).append(x)   # creates the list if missing
groups = defaultdict(list)            # or avoid it entirely

Shortcuts worth knowing

python
from collections import Counter, defaultdict

Counter(s)                   # {item: count} in one call
Counter(s).most_common(1)    # [(most frequent, its count)]
Counter(a) - Counter(b)      # subtract counts, drops zero and below
Counter(a) == Counter(b)     # anagram check in one line

defaultdict(list)            # missing key -> []
defaultdict(int)             # missing key -> 0, so counts[k] += 1 just works

Counter(a) - Counter(b) being empty means b covers a — that’s Ransom Note (383) in one line.

Complexity. Dict and set operations are O(1) average. Using one to replace a nested scan turns O(n²) into O(n), at the cost of O(n) space. That trade is the whole point, and it’s the thing to say out loud in an interview.

[4]Prefix sum

TriggerRepeated range queries, or “how many subarrays sum to k”.
560 Subarray Sum Equals K
python
def subarraySum(self, nums, k):
    counts = {0: 1}
    running = 0
    total = 0

    for num in nums:
        running += num
        if running - k in counts:
            total += counts[running - k]
        counts[running] = counts.get(running, 0) + 1

    return total

A subarray ending here sums to k exactly when some earlier prefix equals running - k. The {0: 1} seed covers subarrays starting at index 0.

Why not sliding windowNegative numbers break monotonicity — growing the window can shrink the sum. Sliding window needs that property; prefix sum doesn’t.

[5]Stack

TriggerMatching or nesting, or anything where you need the most recent thing. A Python list is a stack: append to push, pop() to pop from the end.
20 Valid Parentheses
python
def isValid(self, s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []

    for char in s:
        if char in pairs:
            if not stack or stack.pop() != pairs[char]:
                return False
        else:
            stack.append(char)

    return not stack

Three failure modes, all covered above: wrong type, a closer with nothing open (empty stack), and leftover openers — which is why the last line is return not stack rather than return True.

Monotonic stack

A variant where you keep the stack sorted, popping anything that breaks the order. It’s the answer to “next greater element” problems, and shows up in Microsoft interviews regularly.

Part two — search algorithms

Binary search: the base template

TriggerSorted input and you need better than O(n).
704 Binary Search
python
def search(self, nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) // 2

        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
The two bugs that cause most failuresleft <= right, not < — with < you miss the case where one element remains. And mid + 1 / mid - 1, not mid — using mid stops the range shrinking and loops forever.

A million elements take about twenty steps. O(log n) time, O(1) space.

Binary search for a boundary

When duplicates exist and you want the first or last match, don’t return on equality — record the hit and keep narrowing.

34 Find First and Last Position
python
def findFirst(nums, target):
    left, right = 0, len(nums) - 1
    result = -1

    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            result = mid
            right = mid - 1      # found one, but look further left
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return result

For the last occurrence, flip that one line to left = mid + 1.

Binary search on rotated input

A rotated sorted array still has one sorted half at every step. Work out which half is sorted, then decide whether the target lies inside it.

33 Search in Rotated Sorted Array
python
def search(self, nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid

        if nums[left] <= nums[mid]:              # left half is sorted
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:                                    # right half is sorted
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1

    return -1

Common at Microsoft.

Binary search on the answer

Trigger“Minimum speed”, “smallest capacity”, “least time such that…” — no array to search, but a range of possible answers that’s monotonic. If an answer works, every larger one works too.
875 Koko Eating Bananas
python
def minEatingSpeed(self, piles, h):
    def hours(speed):
        return sum((p + speed - 1) // speed for p in piles)

    left, right = 1, max(piles)

    while left < right:
        mid = (left + right) // 2
        if hours(mid) <= h:
            right = mid          # works, try smaller
        else:
            left = mid + 1       # too slow

    return left

Note this template uses left < right and returns left — the convergence form, used when you’re finding a boundary rather than an exact match. (p + speed - 1) // speed is integer division rounding up.

BFS — breadth first search

TriggerShortest path in an unweighted graph, level-by-level traversal, “minimum number of steps”.

Uses a queue. Explores everything one step away, then everything two steps away — so the first time you reach a target, you got there by the shortest route.

python
from collections import deque

def bfs(grid, start):
    q = deque([start])
    seen = {start}

    while q:
        r, c = q.popleft()

        for dr, dc in ((0,1), (0,-1), (1,0), (-1,0)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]) \
                    and (nr, nc) not in seen and grid[nr][nc] == "1":
                seen.add((nr, nc))
                q.append((nr, nc))
Watch forUse deque and popleft(), not a list and pop(0) — the latter is O(n) per removal. And mark cells as seen when you enqueue them, not when you dequeue, or you’ll add duplicates.

Level order on a tree

Process the queue one full level at a time.

python
def levelOrder(self, root):
    if not root:
        return []

    result = []
    q = deque([root])

    while q:
        level = []
        for _ in range(len(q)):          # snapshot this level's size
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        result.append(level)

    return result

for _ in range(len(q)) captures the level’s size before you start adding the next level. That’s the whole trick.

DFS — depth first search

TriggerExplore every path, count connected regions, anything on a tree.

Uses recursion — the call stack is your stack. Goes as deep as possible, then backs up.

python
def dfs(grid, r, c):
    if r < 0 or r >= len(grid) or c < 0 or c >= len(grid[0]):
        return
    if grid[r][c] != "1":
        return

    grid[r][c] = "0"                 # mark visited

    dfs(grid, r + 1, c)
    dfs(grid, r - 1, c)
    dfs(grid, r, c + 1)
    dfs(grid, r, c - 1)

Every DFS opens with base cases: out of bounds, already visited, or wrong value. Miss one and you recurse forever.

On a tree

The base case is just if not node: return.

python
def maxDepth(self, root):
    if not root:
        return 0
    return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))

The recursive calls return values that get combined on the way back up — the same build-on-the-unwind behaviour as constructing a BST from a sorted array (108).

BFS or DFS?Shortest path calls for BFS. Anything else on a tree or grid, DFS is usually shorter to write.

String mutation

Strings are immutable. You cannot change one in place.

python
s[0] = "x"             # TypeError
s.upper()              # result thrown away - returns a NEW string
s = s.upper()          # correct

Every string method returns a new string and leaves the original alone. This is the opposite of list methods like sort() and append(), which mutate and return None. To “modify” a string, convert to a list, change it, join it back.

python
chars = list(s)        # ["h", "e", "l", "l", "o"]
chars[0] = "H"
s = "".join(chars)     # "Hello"
Watch forBuilding a string with result += c in a loop is O(n²) — each += copies the whole string. Collect into a list and join once at the end instead.

Two-pointer problems that reverse a string in place (344) hand you a list of characters rather than a string, precisely because strings can’t be mutated.
